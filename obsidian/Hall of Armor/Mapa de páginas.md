# Mapa de páginas

| Página | Archivo | Propósito |
|---|---|---|
| Vista general | `pages/vista-general.html` | Resumen del taller y órdenes recientes |
| Órdenes | `pages/ordenes-trabajo.html` | Recepción y ciclo de trabajo |
| Automatizaciones | `pages/automatizaciones.html` | Rutinas y registro de eventos |
| Centro de control | `pages/centro-control.html` | Estado operativo y controles rápidos |
| Vehículos y clientes | `pages/vehiculos-clientes.html` | Fichas e inspecciones próximas |
| Inventario | `pages/inventario.html` | Piezas y alertas de mínimos |
| Hoja de cálculo | `pages/hoja-calculo.html` | Caja y configuración del conector Sheets |
| Dashboard | `pages/dashboard.html` | Indicadores agregados |
| Administrador | `pages/admin.html` | Perfil del taller y permisos de cuentas |
| Soporte | `pages/soporte.html` | Solicitudes del sistema |
| Chat | `pages/chat.html` | Mensajes del taller |
| Notificaciones | `pages/notificaciones.html` | Avisos de operaciones |
| J.A.R.V.I.S. | `pages/jarvis.html` | Asistente técnico de diagnóstico |

Las páginas comparten navegación y eventos mediante `page-shell.js` y `hall.js`. Las vistas antiguas VIMAX bajo `pages/legacy-vimax/` son archivos heredados, no forman parte de Hall of Armor.
